# Portfolio design

Compact personal introduction and project reading column. Desktop has a 248px sticky identity/navigation column, a 112px gutter, and a 720px work column within 1104px. Below 800px the introduction sits above the projects.

Typography: IBM Plex Sans 400/500/600. Name 28px; section headings 20–22px; body 16px; secondary UI 13–14px. Monospace is reserved for the code illustration. No serif display face, slogan hero, decorative numbering, or metadata eyebrows.

Warm neutral canvas #fcfcfa, foreground #282925, secondary #666761. Dark equivalents #191a18, #ecece6, #a6a79e. Color comes from real product screenshots. Images are straight, unshadowed, with 8px container corners. No fake browser chrome or tilted device frames.

Projects carry descriptions, technology lists, direct links, and native expandable build notes. Motion is restricted to short control feedback. Keep reduced-motion support, visible focus, semantic headings, and readable text at narrow widths.

Certificates are always visible as a compact list under About; no disclosure or extra click.
