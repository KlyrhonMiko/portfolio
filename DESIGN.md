# Portfolio design

Compact personal introduction and project reading column. Desktop has a 248px sticky identity/navigation column, a 112px gutter, and a 720px work column within 1104px. Below 800px the introduction sits above the projects.

Typography: IBM Plex Sans 400/500/600. Name 36px (34px mobile), project titles 28px, work heading 24px, contact heading 34px; body 16px; secondary UI 13–14px. Monospace is reserved for the interactive code illustration. No serif display face, slogan hero, decorative numbering, or metadata eyebrows.

Warm neutral canvas #fcfcfa, foreground #282925, secondary #666761. Dark equivalents #191a18, #ecece6, #a6a79e. Personal accent #286047 in light mode, #9bceb0 in dark mode. Use it for current navigation, project links, engineering decisions, and contact. Koin uses a split product gallery: a compact feature index on the left and one large, complete app screenshot on a muted mint stage on the right. Overview, Activity, and Budgets are selectable at every viewport width. Mobile puts the controls above the screenshot. pars. uses a wide gallery of real editor and résumé-review screenshots, with understated text controls and a full-size image link. No invented editing UI, marketing slogans, browser chrome, or tilted device frames. Showcase corners are 8px. Product screenshots retain their original appearance; Koin screenshots follow the site theme.

Projects carry descriptions, a visible engineering decision, technology lists, direct links, and native expandable build notes. nulll includes a user-triggered Python loop illustration with active code, values, printed output, completion, and restart. Motion is restricted to short control feedback and arrow movement. Keep reduced-motion support, visible focus, semantic headings, and readable text at narrow widths. Sidebar navigation tracks the current section. Contact gets a larger heading and underlined email action.

Certificates are always visible as a compact list under About; no disclosure or extra click.

The résumé route shares the portfolio's IBM Plex Sans, neutral theme, sidebar alignment, and reading column. It reflows on mobile without scaling. Printing hides navigation and uses a plain light document. The existing downloadable PDF remains a separate asset.

The Creative version link points directly to https://creative.klyrhon.me. Its animated design is deployed independently from the previous branch.
